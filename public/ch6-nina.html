Script · One Word Changes Everything

One Word Changes Everything

One word changes everything.

Not a long word. Not a technical one. A verb. The action word in a prompt is the single most precise instruction you give to an AI system. It tells the model exactly what cognitive operation to perform.

Consider the difference:

'Tell me about renewable energy.'

The model interprets this as a request for general information. It does not know whether you want a summary, a comparison, an analysis, or a list. So it produces all of them — explanation, context, examples, commentary — in a single response. More tokens than needed. More breadth than depth. Likely not what you required.

'Compare the levelised cost of energy for solar, wind, and nuclear power in a table.'

The model now has a specific cognitive task: comparison. A specific structure: a table. A specific scope: three energy types, one metric. The output is focused, structured, and ready to use on first generation.

Same domain. Different verb. Completely different result.

The action element of C.R.A.F.T. is about specifying the cognitive operation — precisely.

Script · Action Verbs and Token Efficiency

Why the Verb Determines the Cost

Vague action language — 'tell me about,' 'help me with,' 'write something on' — forces the model to infer intent. It hedges by producing multiple output types simultaneously: explanation, analysis, listing, and commentary in a single response. The result is over-generation. More tokens than necessary, lower relevance, higher probability of requiring a retry.

Precise action language — 'compare,' 'evaluate,' 'classify' — constrains the generation to a single cognitive operation. The model produces a focused output aligned with the specified task.

The measurable impact is significant. Moving from vague to precise action language represents a 74 percent reduction in output tokens and a 90 percent reduction in retry rate. At the scale of organisational AI use — thousands of prompts per day — this translates directly to measurable compute and energy savings.

The verb is not decoration. It is the instruction.

Ten Verbs — Read as Spoken List

Ten action verbs. Each one triggers a different type of thinking. Pause between each.

List. Items in sequence — no explanation, just the items.

Summarise. Key points only — short, no detail.

Compare. Side-by-side differences between two or more things.

Explain. Step-by-step understanding — how or why something works.

Analyse. Break apart and examine the components.

Evaluate. Judge quality — weigh evidence, assess pros and cons.

Create. Build something new — a plan, a draft, a design.

Classify. Sort into categories.

Predict. Project what might happen based on current information.

Justify. Give evidence-backed reasons for a position.

One prompt. One verb. One clear task.

Script · The One-Verb Rule

One Prompt, One Verb

The one-verb rule is a design constraint, not a limitation.

Multi-action prompts — 'explain and compare and also suggest' — create competing generation objectives. The model must allocate attention across multiple task types simultaneously, producing outputs that partially satisfy each but fully satisfy none. The output is longer, less focused, and more likely to require follow-up.

The rule is simple: one prompt, one primary action verb. If a task requires multiple cognitive operations, decompose it into sequential prompts — each with a single action, each building on the output of the previous one.

Sequential single-action prompts produce lower total token counts than a single multi-action prompt, because the multi-action prompt generates redundant transitional text as the model shifts between task types.

This principle extends to how complex work should be structured with AI: not as one large, ambiguous request, but as a sequence of precise steps. Each step specified. Each verb chosen deliberately.
